# DCC Types

Literally just stub `pyi` files, for the most common 3D DCC's.

## About

Inspired by [typeshed](https://github.com/python/typeshed), this repository houses type annotations for well known 3D applications.

Also added are proper documentation and overloading features, although we are not strictly following python overload conventions, but more generalized coding conventions that other languages benifit from.

This is a personal project at the moment, but I hope it helps others!
